# Fonts

Put a TTF at `fonts/default.ttf` (or point `FONT_PATH` elsewhere). Without it, Pillow's
built-in font is used, which is readable but not manga-like.

Good free comic lettering fonts (check license before commercial use):

- Komika Text / Komika Axis (Apostrophic Labs, free)
- Anime Ace 2.0 BB (Blambot, free for indie use)
- CC Wild Words (Comicraft, paid, the industry standard)
